# Aditi Boutique Website

A responsive six-page static website for Aditi Boutique.

## Pages
- `index.html` — Home
- `about.html` — Our Story
- `collections.html` — Collections
- `services.html` — Craft & Services
- `careers.html` — Careers
- `contact.html` — Contact

## Run locally
Open `index.html` in a browser. No build tools are required.

## Customisation
- Edit `style.css` to change colours, fonts and layout.
- Edit each HTML page to update content and images.
- Images currently load from Unsplash URLs, so an internet connection is needed to display them.

## Important
The contact form is a front-end demo and does not send or store messages. Connect it to a backend or a form service before publishing.
